# @deepseek-ai/dsh-client-ui-usage-stats

[English](README.md) | 中文

## 概述

页面打开时展示最近 30 天的本地用量历史，7 天与手动刷新只需一次点击。它沿用现有的 `settings.section` 项 `usage-stats`。其后依次是概览数值、活动网格、每日 Token 趋势、模型圆环与 Token 构成。每一项都在悬停或聚焦时揭示自身数值：格子或日期列打开详情卡，模型排行行与圆环弧段互相高亮。刷新与范围切换保留已提交数据，过期响应被忽略，失败提供重试，无法解读的会话被报告而不计入。精确数值保留在无障碍名称与表格中。

<a id="reading-the-dashboard"></a>
## 如何阅读仪表盘

概览长条给出所选范围的 Token 总量、会话数、消息数、活跃天数与当前连续活跃。紧凑写法会丢失精度的数值，会把精确值作为悬停与聚焦提示，因此没有哪个数值只能靠近似读取。最常用模型写在模型用量卡片的标题旁，紧邻呈现它的圆环。

活动网格按 Token 为每个 Host 日历日着色的方格，色阶取范围最大值的三等分。它的切换决定一个方格报告什么：**每日**是当天；**每周**是包含该日的、以周一开始的那一周，因此同一周的所有方格报告同一合计；**累计**是截至当天的累计值。周起点固定为周一，使该指标是日期的函数而不是浏览者区域设置的函数。当存在可见消息而提供方没有报告 Token 时，网格会说明这一点，而不是把该范围呈现为闲置。

趋势卡片把同一批日期画成每个 Token 桶一条折线，或画成每日堆叠柱。两种形态共用同一批日期列，因此悬停或聚焦揭示同一张详情卡、放置同一条十字准线；指向图例项会让其余序列后退。折线按最大的单个桶取值定标，堆叠柱按最大的每日合计定标，范围更长时刻度标签会抽稀。

模型圆环每段画成一条描边弧线，因此弧段的指针区域正是读者看到的那一段。它与趋势图共用固定系列色板。排行列出每个模型占范围的份额与 Token 总量，超出前四名的模型合并为最后一段。

<a id="model-experience"></a>
## 模型体验

无，因为该浏览器插件只呈现 Host 派生数据，不增加模型可见内容。

#### KV Cache 影响

无；它不参与提供方请求。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- 页面只在挂载、切换范围或用户手动操作时刷新，不自动轮询。
- 活动网格跟随所选的 7 天或 30 天范围，因此是密集方格而非全年日历：方格所属日期来自其无障碍名称与详情卡，而不是坐标轴。
- 可视化使用五种现有语义系列色；标签、固定顺序、无障碍摘要和完整表格在不依赖颜色时保留相同区分。
- 页面刻意不展示费用、余额、套餐、额度和模型价格，因为 Host 服务无法证实这些信息。
